# Reel Style Guide — "Neon Glass Stack" format

Breakdown of the reference reel by @robin_linkerpro ("The perfect structure for short-form content").
Specs: 1080×1920 vertical, 30 fps, ~34 s, voiceover + music, no hard cuts — everything is animated motion graphics.

## 1. Script structure (the 8 blocks)

| # | Block | Job | Time in reference |
|---|-------|-----|-------------------|
| 1 | Hook | Break the scroll pattern ("Wait, what?") | 0–3 s |
| 2 | Lead | Hold viewer to the 10-second mark | 3–10 s |
| 3 | Body 1 | First piece of value | ~10–14 s |
| 4 | Open loop | One curiosity line: "But that's not the craziest part…" | ~14–19 s |
| 5 | Body 2 | Second value | |
| 6 | Open loop | Second curiosity line | |
| 7 | Body 3 | Last value | |
| 8 | CTA | Move the warmest viewers to the next step (save / follow / link) | last ~6 s |

The reel **teaches the structure while using it** — meta format. Ends with "Save this before you write your next script."

## 2. Visual style

- **Background:** near-black deep navy/purple space, faint stars, soft blurred colour nebulas (magenta bottom-left, teal right), a perspective neon grid floor in the lower third (synthwave/Tron feel).
- **Material:** frosted **glass / glowing 3D slabs** with neon edge light, inner gradient, subtle reflections. Everything floats with a slight 3D tilt.
- **One colour per concept** (consistent through the whole video):
  - Hook = hot pink/magenta · Lead = amber/gold · Body = cyan/teal · Open loop = violet/purple · CTA = mint green
- **Typography:** heavy rounded geometric sans (like *Satoshi / General Sans / SF Pro Rounded Bold*). Big title top-centre with a gradient fill matching the block colour + soft outer glow. Tiny monospace UPPERCASE labels for UI details ("SHORT-FORM · STRUCTURE", "VIEWER RETENTION", "ONE LINE", "CURIOSITY") with small numbers like `01`, `02`.
- **UI details that sell the look:** pill tags with a coloured dot ("• breaks the pattern", "• pulls them to 10s", "• warmest viewers"), a small counter top-right (`02/08`), progress bar segmented into 8 colour chips at the top, fake app cards (retention graph "10.0s", text box with typing cursor, "Next step →" button, "Save this" bookmark button with mouse cursor click).

## 3. Scene-by-scene (reference)

1. **Intro build:** "SHORT-FORM · STRUCTURE" header + counter 01/08→08/08; glass slabs drop in one by one stacking into a tower (each slab labelled `01 Hook`, `02 Lead`…).
2. **Title card:** "The perfect structure" + pill "for short-form content", tower shrinks to the middle.
3. **One scene per block** — big coloured title at top, one central 3D icon/metaphor, one pill tag:
   - Hook → tilted pink card "Wait, what?" breaking out of a feed of grey placeholder posts.
   - Lead → retention graph card counting 10.0s → 14.3s, "🔒 anchored" badge.
   - Body → glowing glass cube labelled "VALUE" on ripple rings.
   - Open loop → ring that draws itself, "?" appears; text box types "But that's not the craziest part…" with a curiosity meter filling.
   - Repeat ×2 → tower returns, brackets show ×1, ×2, "last body".
   - CTA → funnel made of 3 glowing rings with avatar faces falling to the bottom; "Next step →" button.
4. **Outro:** "8 blocks" + full tower + "Save this" button that gets clicked → "Saved".

## 4. Motion & editing

- No cuts: transitions are morphs (tower shrinks/moves, titles fade-swap, elements scale in with overshoot/spring).
- New element appears every ~1–2 s; constant gentle float/bob + slow camera drift.
- Progress bar at top fills chip by chip as the script advances.
- **Captions:** bottom-centre, inside a dark rounded pill, 2–4 words at a time, word-by-word highlight (spoken word bright white with coloured underline, upcoming words dimmed grey).
- Audio: calm, fast-paced voiceover + low ambient/electronic bed; small UI "pop/click" SFX on each appear (suggested).

## 5. How to recreate it

- **Tools:** After Effects (3D layers + glow + Saber) or **Rive/Jitter/Figma + Jitter**, or code (Remotion / Motion Canvas) — all can produce this exactly. CapCut alone gets ~70% there with PNG glass assets + keyframes.
- **Template recipe:** dark gradient bg → grid floor → nebula blobs (blurred ellipses) → glass slab = rounded rect, 20–30% fill of block colour, 1–2 px bright stroke, outer glow 30–60 px, slight skew.
- **Swap topic:** keep the 8-colour system and "one metaphor per block" — just replace labels, icons and the script.
